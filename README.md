# Simple To‑Do Web App

A minimal to‑do app built with plain HTML, CSS, and JavaScript (no frameworks).

## Run locally

- Open `index.html` directly in your browser, or start a static server:

```bash
python3 -m http.server 5173 --bind 127.0.0.1 | cat
```

Then visit `http://127.0.0.1:5173/`.

## Features

- Add, complete, and delete tasks
- Tasks are saved in your browser (localStorage)
- Accessible and responsive UI
